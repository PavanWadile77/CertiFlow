An AI-assisted digital certificate platform for **certificate creation, management, distribution, and QR-based verification**.

## ✨ Features
- Digital certificate creation and management
- QR code generation and scanning
- Certificate verification workflow
- Firebase integration
- AI-assisted capabilities
- Responsive modern UI

## 🛠️ Tech Stack
**React 19 · TypeScript · Vite · Firebase · Google Gemini · QRCode React · QR Scanner · Tailwind CSS · Motion · Express**

## ▶️ Run Locally
```bash
git clone https://github.com/PavanWadile77/CertiFlow.git
cd CertiFlow
npm install
npm run dev
```
